## File Viewer

### Glim

A free, MIT-licensed file viewer for Markdown, PDFs, images, source code, and data files, with basic UTF-8 text editing. Available for Apple Silicon and Intel.

- Website: <https://github.com/NeoPanic/Glim>

- Download: <https://github.com/NeoPanic/Glim/releases/latest>
