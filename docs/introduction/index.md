# Introduction

This site lists software I personally recommend. Some of them I use regularly. It's split up by platform and mostly [FOSS](https://www.gnu.org/philosophy/free-sw.html) and privacy-friendly.

This is a personal list, not a place to promote projects. Pull requests that add software will be closed, especially if you made or work on that software. If you use something you think belongs here, suggest it in an [issue](https://github.com/D3SOX/awesome-software/issues) and I'll take a look. Pull requests that fix broken links, typos, or outdated information are welcome.
